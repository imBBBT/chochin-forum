# Chochin Forum

A modern, feature-rich community forum built with Jekyll and GitHub Pages.

## Features

- **Responsive Design**: Built with Bootstrap 5 for a seamless experience on all devices.
- **Discussions**: Main area for general announcements and community discussions.
- **Project Showcases**: Dedicated space for members to share their work.
- **Q&A**: Knowledge base for asking and answering questions.
- **User Profiles**: Built-in Jekyll user profile system.
- **Contact Page**: Easy way for visitors to get in touch.
- **RSS Feed**: Automatic RSS feed generation for subscriptions.
- **GitHub Integration**: Native integration with GitHub for easy deployment and collaboration.

## Getting Started

### Prerequisites

- [Ruby](https://www.ruby-lang.org/) (3.0.0 or higher recommended)
- [Bundler](https://bundler.io/) (gem install bundler)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd chochin-forum
   ```

2. Install dependencies:
   ```bash
   bundle install
   ```

3. Run the development server:
   ```bash
   bundle exec jekyll serve
   ```

4. Open your browser and navigate to `http://localhost:4000`.
